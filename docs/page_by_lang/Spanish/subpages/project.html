El proyecto

Cada recolección sigue la misma rutina, para que los datos sean comparables entre días:

  1. Recolección — recorro un tramo de playa, con los cuatro puntos de esquina georreferenciados (coordenadas anotadas en campo);
  2. Separación — separo el material (análisis cualitativo);
  3. Pesaje — peso todo (análisis cuantitativo: orgánico × inorgánico);
  4. Registro & publicación — un CSV de campo guarda todo; scripts de Python (pandas, geopandas, shapely) lo transforman y generan el mapa web interactivo (Leaflet, publicado vía GitHub Pages).
