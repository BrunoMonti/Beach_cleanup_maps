Sobre mim

Olá, sou o Bruno. Desde setembro de 2023 recolho resíduos das praias de Florianópolis (SC, Brasil) e transformei a rotina num projeto de dados: cada coleta é separada (qualitativa), pesada (quantitativa), georreferenciada e publicada aqui como dados abertos.

O objetivo é simples: tornar o invisível visível — medir o resíduo que chega à praia, compartilhar os números e abrir o projeto para os dados de outras pessoas.

Contribuindo

Quer contribuir com dados da sua praia? Entre em contato — estamos estruturando um banco compartilhado (PostgreSQL/PostGIS) para receber coletas de qualquer lugar.
