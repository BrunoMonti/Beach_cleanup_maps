O projeto

Toda coleta passa pela mesma rotina, para que os dados fiquem comparáveis entre os dias:

  1. Coleta — percorro um trecho de praia, com os quatro pontos de canto georreferenciados (coordenadas anotadas em campo);
  2. Separação — separo o material (análise qualitativa);
  3. Pesagem — peso tudo (análise quantitativa: orgânico × inorgânico);
  4. Registro & publicação — um CSV de campo guarda tudo; scripts Python (pandas, geopandas, shapely) transformam e geram o mapa web interativo (Leaflet, publicado via GitHub Pages).
